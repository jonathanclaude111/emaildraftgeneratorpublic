# emaildraftgeneratorpublic

Online versie van het formulier **Mailsjablonen automatisch**, om te openen via een link (bv. op iPhone of Android).

- `index.html`: het formulier (kopie van `mailsjablonen-automatisch.html`).
- `contacts_example.xlsx`: voorbeeldcontacten om te testen (geen echte klanten).

Veilig om publiek te zetten: in de pagina zitten geen klantgegevens. Excel-bestanden worden alleen op je eigen toestel gelezen; de beveiliging (CSP) blokkeert elke internetverbinding vanuit de pagina.

Zonder bijlagen opent de mail via een mail-link; met bijlagen (of een heel lange mail) maakt de tool een Outlook-bestand (.eml).
